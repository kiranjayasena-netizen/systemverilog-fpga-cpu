# Book Release Checklist

- [ ] The release tag points to the book's authoritative commit.
- [ ] README commands and internal links have been checked.
- [ ] All files referenced by the book exist in the release.
- [ ] The XSim regression passes with the documented Vivado version.
- [ ] The published implementation script completes successfully.
- [ ] Setup, hold and unconstrained-path checks pass.
- [ ] The benchmark and board controls match the book.
- [ ] Major numerical claims match retained reports.
- [ ] Simulation, timing-derived and physical evidence are labelled separately.
- [ ] The licence, citation metadata and copyright scope are correct.
- [ ] The release archive can be downloaded while signed out of GitHub.
- [ ] The book QR code resolves to the permanent public release.
