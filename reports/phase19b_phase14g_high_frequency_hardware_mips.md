# Phase 19B Phase 14G High-Frequency Hardware MIPS Test

## Purpose

Phase 19B creates high-frequency MMCM hardware-test wrappers for the Phase 14G six-stage CPU. Phase 14G previously had the strongest timing-estimated result, about 101.8 MIPS at 166.667 MHz, but it had not been physically measured on the board at that clock.

This phase creates timing-clean board-test wrappers and records the first high-frequency physical MIPS measurement for the Phase 14G six-stage CPU.

## CPU And Wrapper

| Item | Value |
| --- | --- |
| CPU core | `cpu_core_pipeline6` |
| New wrapper | `rtl/fpga_top_phase19b_pipeline6_mmcm_mips.sv` |
| Board | Digilent Basys 3 |
| FPGA part | `xc7a35tcpg236-1` |
| Program image | `programs/fpga_led_demo.mem` |
| Measurement | retired instructions per one CPU-clock-domain second |

The wrapper uses:

- RTL-instantiated 7-series MMCM.
- CPU-clock-domain one-second measurement window.
- `CPU_CLOCK_HZ` matched to the generated CPU clock.
- SW0 as run enable.
- BTNC as reset.
- LED0 as MMCM lock.
- SW3:SW1 display mode selector.
- 7-segment display mode `000` for integer MIPS.

The Phase 14G CPU RTL was not modified.

This is the first physical high-frequency board result for the Phase 14G six-stage CPU. It does not validate the separate 166.667 MHz timing-estimated value, because the 166.667 MHz Phase 19B measurement wrapper failed setup timing.

## Failed 166.667 MHz Critical Path

The 166.667 MHz run failed by 0.102 ns after post-route physical optimisation:

- Source: `impl/cpu_inst/op_ex_reg_reg[operand_b][25]/C`
- Destination: `impl/cpu_inst/fetch_pc_reg_reg[30]/D`
- Requirement: 6.000 ns
- Data path delay: 6.121 ns
- Logic delay: 3.173 ns
- Route delay: 2.948 ns
- Logic levels: 12 (`CARRY4=9 LUT3=1 LUT6=2`)

This path is consistent with execute/control redirect and fetch PC update logic being the remaining high-frequency limiter.

## Board Test Procedure

For each valid Phase 19B bitstream:

1. Program the Basys 3.
2. Press and release BTNC reset.
3. Confirm LED0 is on for MMCM lock.
4. Set SW0 = 1 to run.
5. Set SW3:SW1 = `000` for MIPS mode.
6. Wait at least two one-second measurement windows.
7. Record the 7-segment display.
8. Take photo/video evidence.

## Interpretation

Phase 19B produced timing-clean Phase 14G/six-stage board-test candidates at 150, 155 and 160 MHz. The 160 MHz board test displayed `0101`, approximately 101 MIPS. The 166.667 MHz timing-estimated target did not close in this hardware-measurement wrapper.

The result confirms that the six-stage CPU can physically cross 100 MIPS on the Basys 3 when clocked above 100 MHz, while also showing that the 166.667 MHz / approximately 101.8 MIPS timing-estimated result still needs a timing-clean measurement wrapper before it can be treated as board evidence.
